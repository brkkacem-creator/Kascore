Kascore sur Android

2 méthodes d'installation · Coupe du Monde 2026

⚡ Recommandé · 30 secondes

La PWA s'installe comme une vraie app depuis Chrome, sans passer par le Play Store. Mises à jour automatiques, mode hors-ligne inclus.

1

Déploie Kascore sur Vercel

Lance LANCER_KASCORE.sh puis pousse sur GitHub → Vercel. Tu obtiens une URL publique type kascore.vercel.app

2

Ouvre l'URL dans Chrome Android

Sur ton téléphone, ouvre Google Chrome et va sur ton URL Kascore.

3

Installe depuis Chrome

Chrome affiche automatiquement une bannière "Ajouter à l'écran d'accueil".
Ou : menu ⋮ → Ajouter à l'écran d'accueil

4

L'icône Kascore apparaît 🎉

L'app s'ouvre en plein écran, sans barre Chrome. Elle fonctionne même partiellement hors connexion.

Pourquoi la PWA ?
Mêmes fonctionnalités qu'une app native, mises à jour instantanées (pas besoin de réinstaller), et aucune démarche Play Store.
🔧 APK natif · ~15 min de build

Génère un vrai fichier .apk installable directement. Nécessite Android Studio une seule fois.

Prérequis

☕
Java JDK 17+
adoptium.net →
🤖
Android Studio
developer.android.com/studio →
📦
Node.js 18+
nodejs.org →
1

Configure l'URL dans .env.local

Assure-toi que NEXT_PUBLIC_APP_URL pointe vers ton Vercel déployé.

2

Lance le script de build

Dans le dossier kascore :

bash BUILD_APK.sh

Le script construit Next.js, sync Capacitor, et compile l'APK.

3

Récupère kascore-android.apk

Le fichier est créé à la racine du projet.

4

Installe sur Android

Via USB (recommandé) — câble branché, débogage USB activé :

adb install kascore-android.apk

Via fichier — copie l'APK sur le téléphone et ouvre-le. Autorise les "sources inconnues" dans Paramètres → Sécurité.

5

Alternative : Android Studio

Ouvre android-build/ dans Android Studio → Run ▶ pour installer directement sur le téléphone connecté.

Activer les sources inconnues :
Paramètres → Sécurité → Installer des apps inconnues → Chrome (ou Gestionnaire de fichiers) → Autoriser
